# yt-dlp Ingest

## Summary

A cloud-hosted yt-dlp tool that downloads media directly into the user's cloud storage.

## Initial Direction

The tool should run yt-dlp in the cloud and write downloaded files into the shared storage layer.

## Core Capabilities

- Run yt-dlp jobs in cloud infrastructure.
- Store downloaded files in selected cloud storage directories.
- Integrate with the cloud storage wrapper.
